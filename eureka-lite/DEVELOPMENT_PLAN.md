# Eureka Lite Phase 1 开发计划

> **目标**：完成 MVP 核心功能
> **周期**：预估 4-6 周（单前端开发）
> **技术栈**：HTML5 + CSS3 + Vanilla JS + LocalStorage

---

## 0. 视觉风格确定

### 首页参考：Gemini App 风格

**核心特征：**
- **深色背景**（#0D0D0D 或纯黑）
- **大字体问候语**："David，你好 / 今天想让我做点什么？"
- **快捷入口胶囊按钮**：圆角大按钮，带图标，垂直排列
- **底部固定输入框**：圆角输入框 + 功能按钮（语音、快速模式等）
- **侧边抽屉**：历史记录、我的内容、设置

**Eureka Lite 适配：**

```
┌─────────────────────────┐
│ ≡  Eureka Lite     🔔 D │  ← 顶部：菜单 + Logo + 通知 + 头像
├─────────────────────────┤
│                         │
│   David，你好           │  ← 大字体问候（根据时间变化）
│   今天想创新点什么？     │
│                         │
│   ┌───────────────┐     │
│   │ 🔮 为你推荐    │     │  ← 快捷入口胶囊
│   └───────────────┘     │
│   ┌───────────────┐     │
│   │ 🛠️ 产品创新    │     │  ← 四类创新类别
│   └───────────────┘     │
│   ┌───────────────┐     │
│   │ 🎨 服务体验    │     │
│   └───────────────┘     │
│   ┌───────────────┐     │
│   │ 🔍 复杂问题    │     │
│   └───────────────┘     │
│   ┌───────────────┐     │
│   │ 💡 探索验证    │     │
│   └───────────────┘     │
│                         │
├─────────────────────────┤
│ ┌─────────────────────┐ │
│ │  描述你的问题...    │ │  ← 底部固定输入框
│ └─────────────────────┘ │
│  [📎] [🎤] [⚡快速]    │
└─────────────────────────┘
```

**工作台风格：**
- 从首页进入后，根据 RISE 四步切换**四种主题色**
- Reveal: 橙色系 (#E07A2F)
- Inspire: 紫色系 (#7F77DD)
- Shape: 绿色系 (#0F6E56)
- Exam: 银灰色系 (#64748B)

## 1. 开发里程碑

### Week 1: 基础架构 + 首页

**目标**：可运行的首页，能输入问题并选择类别

## 3. 关键交互设计

### 首页 → 工作台 流转

```
用户输入问题 → 选择类别 → 进入 Reveal 第 1 屏
                    ↓
              或选择快捷入口
                    ↓
         系统推荐场景 → 用户确认 → 进入 Reveal
```

### AI 助手 standby 模式

```
[悬浮按钮 💡 在右下角]
    ↓ 点击
[展开面板]
├─ 给我建议
├─ 参考案例
├─ 帮我预填
└─ 反馈优化
    ↓ 选择
[AI 回复在面板内显示]
    ↓ 用户操作
[应用到当前卡片 / 关闭]
```

### 卡片生成与查看

```
完成一屏 → 自动生成/更新卡片 → 卡片预览在页面下方
    ↓
完成全部 3-5 屏 → 进入卡片确认页 → 可编辑/确认
    ↓
确认后 → 卡片存入项目库 → 可进入下一步
```

## 4. 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 6 周做不完 | 延期 | 优先保证 Reveal + Inspire 可用，Shape/Exam 可简化 |
| 移动端适配复杂 | 体验差 | Week 1 就开始移动端测试，不做桌面优先 |
| localStorage 容量限制 | 数据丢失 | 定期提示用户导出，控制单项目数据大小 |
| AI 预填质量不稳定 | 用户体验差 | 预填内容明确标注"AI 建议，请修改确认" |
| 用户不理解 RISE 流程 | 流失 | Week 1 加入新用户引导，解释四步是什么 |
