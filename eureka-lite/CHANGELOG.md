# Changelog

## v1.0.0 (2026-07-29)

### 核心功能
- **RISE 完整方法论闭环**：Reveal（洞察）→ Inspire（启发）→ Shape（塑造）→ Exam（验证），四阶段 19 屏完整流程
- **AI 主动辅助**：支持 DeepSeek / 混元 / GPT 等多品牌 API，用户自定义 Key
- **项目全景图**：四阶段核心产出汇总展示，支持导出 HTML / 打印 PDF / 保存图片
- **示例项目 MOMOS**：预装完整四阶段示例，新手零门槛上手（附每屏操作指南）
- **积分/Pro 解锁**：完成一个项目 +600 分，累计 1200 分解锁 Eureka Pro

### 体验优化
- 首页「一张图看懂 RISE」新手引导流程图
- 项目卡片布局（标题/进度/删除按钮）
- 顶部 RISE Stepper 阶段高亮跟随导航
- AI 配置弹窗保存按钮亮橙色
- 项目全景图配色修复（深色/浅色主题兼容）

### 稳定性
- 导航守卫：阶段切换时自动保存当前内容
- 模块导航高亮跟随当前阶段
- 同步推送双仓库（eureka-lite + marketplace）

### Bug 修复
- 示例项目 API 名称错误（`createProject` → `addProject`）
- 项目卡片 HTML 结构缺失关闭标签导致标题不显示
- `createProject` 遗漏 `isExample` 字段导致示例项目指南不渲染
- 抽屉默认关闭后无法打开
- 项目卡片防删除二次确认
- 30-60-90 天计划表格第一列黑底黑字
- 模态「参考示例」卡深色主题下不可见

### 技术说明
- 纯 Vanilla JS SPA，零构建步骤，零依赖
- 数据存储于浏览器 localStorage，完全离线可用
- GitHub Pages 部署，不支持 IE 等老旧浏览器

### 已知问题
- app.js（~8400 行）单体较大，计划逐步拆分为模块
- 无实时协作功能（单人工具）
- 英文版本尚未实现（计划中）
