# Find Insight Skill

这是Eureka! AI价值创新系统的第四个Skill，负责运用FIND模型从用户旅程事实中挖掘深层需求洞察。

## 核心功能

运用FIND模型（Facts → Interpret → Need → Design Insight）从用户旅程事实中挖掘深层需求：

1. **Facts（事实收集）**
   - 用户行为观察记录
   - 访谈和调研数据
   - 旅程触点的具体事件
   - 可观察的客观事实

2. **Interpret（行为解读）**
   - 行为背后的动机
   - 用户的心理状态
   - 情感和态度分析
   - 为什么会有这种行为

3. **Need（需求推断）**
   - 显性需求（直接表达的需求）
   - 隐性需求（未表达但真实需要的需求）
   - 情感需求（感受、动机）
   - 深层需求（价值观、身份认同）

4. **Design Insight（设计洞察）**
   - 需求的本质是什么
   - 为什么这个需求重要
   - 如何通过设计满足这个需求
   - 启发性的洞察陈述

## FIND模型详解

### 1. Facts（事实）

**收集原则**:
- 客观、可观察
- 具体的行为和事件
- 避免主观判断
- 记录时间、地点、人物、行为

**示例**:
```
❌ 错误：顾客不懂得挑选
✅ 正确：顾客在货架前停留了8分钟，拿起3件商品又放回，最终没有购买
```

### 2. Interpret（解读）

**解读维度**:
- 行为动机：为什么这么做？
- 心理状态：当时的感受是什么？
- 情感反应：满意、焦虑、困惑、愉悦？
- 态度倾向：积极、消极、中性？

**示例**:
```
Facts: 顾客在货架前停留8分钟，拿起3件商品又放回，最终没有购买

Interpret: 
- 顾客被选项过多所困扰
- 感到决策压力和焦虑
- 害怕做出错误的选择
- 缺乏决策的信心
```

### 3. Need（需求）

**需求层次**:

**显性需求**（直接表达的需求）
- "我想要更快地找到合适的商品"
- "我需要专业的搭配建议"

**隐性需求**（未表达但真实需要的需求）
- "我希望决策过程不会显得我很无能"
- "我想要掌控感，不想被推销"

**情感需求**（感受、动机）
- "我希望感到被理解和尊重"
- "我想要获得购物的愉悦感"

**深层需求**（价值观、身份认同）
- "通过购买决策表达自己的品味和身份"
- "追求效率，体现现代都市女性的独立"
- "渴望获得专业的认可"

### 4. Design Insight（设计洞察）

**洞察结构**:

**洞察陈述**：
"[用户]在[场景]中[行为]，这意味着[深层需求]，所以我们应该[设计方向]"

**设计启发**：
- 基于洞察的设计原则
- 具体的设计建议
- 可以采取的行动

**示例**:
```
Insight: 
Lisa在选购职业装时面对200+款商品反复试穿8次最终放弃，
这意味着她的深层需求不是"更多选择"，而是"更聪明的选择"，
所以我们应该设计一个智能决策支持系统，帮她快速筛选并建立决策信心。

Design Principles:
- 减少，而不是增加选项
- 引导，而不是推销
- 赋能，而不是替代
```

## 与系统的集成

- **上游**: `build_project_brief` - 提供用户画像和场景背景

## 关键原则

1. **客观事实**: Facts必须是可观察、可验证的客观事实
2. **深度解读**: Interpret要挖掘行为背后的深层动机和心理
3. **全面需求**: Need要覆盖显性、隐性、情感、深层四个层次
4. **可操作洞察**: Design Insight要能指导具体的设计决策
5. **情感共鸣**: 洞察要能触动用户情感，激发创新思维
