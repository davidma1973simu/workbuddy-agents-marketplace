# Pitch_Composer - 电梯呈现脚本撰写者

## 📋 基本信息

- **Skill ID**: `Pitch_Composer`
- **Skill 名称**: 电梯呈现脚本撰写者
- **所属 Agent**: Exam Specialist（验证官）
- **版本**: v1.0.0
- **类型**: 创意类

---

## 🎯 功能定义

**核心功能**：基于方案和测试结果生成 60 秒电梯呈现脚本

**呈现目的**：
- 快速传递项目价值
- 吸引投资者关注
- 获得投资支持

---

## 📝 电梯呈现结构

### 标准 60 秒电梯呈现结构

#### 1. 开场（10 秒）- 抓住注意力

**内容**：
- 描述问题或痛点
- 引起共鸣
- 快速进入主题

**示例**：
```
每个人都有这样的经历：在电商平台上浏览了几个小时，面对海量选择，不知道选哪个，感到焦虑和困惑。
```

---

#### 2. 解决方案（15 秒）- 介绍方案

**内容**：
- 方案名称
- 核心功能
- 核心价值

**示例**：
```
我们的产品 ShopMate AI 就是为了解决这个问题。它是一个基于 AI 的智能购物助手，用户只需要用自然语言描述需求，AI 就能在 30 秒内推荐最适合的产品。
```

---

#### 3. 验证（15 秒）- 证明价值

**内容**：
- 测试结果
- 用户反馈
- 量化指标

**示例**：
```
我们测试了 10 位用户，结果显示：用户节省了 95% 的购物时间，决策信心提升了 65%，满意度从 3 分提升到 5 分。
```

---

#### 4. 市场机会（10 秒）- 展示潜力

**内容**：
- 市场规模
- 增长潜力
- 竞争优势

**示例**：
```
市场规模 100 亿元，年增长率 30%。我们的优势是更中立、更智能、更高效。
```

---

#### 5. 行动号召（10 秒）- 明确诉求

**内容**：
- 融资需求
- 使用计划
- 下一步行动

**示例**：
```
我们正在寻找 100 万的种子轮融资，用于产品开发和市场推广。如果您感兴趣，我们可以深入交流。
```

## 🎯 质量标准

### 脚本结构质量

| 指标 | 标准 |
|------|------|
| 时长控制 | 60 秒内可以说完（约 150-200 字） |
| 结构完整 | 包含开场、解决方案、验证、市场机会、行动号召 |
| 逻辑清晰 | 逻辑清晰，层次分明，易于理解 |

### 内容质量

| 指标 | 标准 |
|------|------|
| 价值突出 | 突出核心价值和亮点 |
| 数据支撑 | 有测试数据支撑，可信度高 |
| 故事吸引 | 有故事性，能吸引注意力 |
| 号召有力 | 有明确的行动号召 |

### 语言质量

| 指标 | 标准 |
|------|------|
| 简洁明了 | 简洁明了，不啰嗦 |
| 口语化 | 口语化，易于表达 |
| 情感共鸣 | 能引起情感共鸣 |
| 专业可信 | 专业可信，有说服力 |
