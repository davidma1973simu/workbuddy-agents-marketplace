# AHA_MAP_Evaluator - AHA_MAP 评估师

## 📋 基本信息

- **Skill ID**: `AHA_MAP_Evaluator`
- **Skill 名称**: AHA_MAP 评估师
- **所属 Agent**: Exam Specialist（验证官）
- **版本**: v1.0.0
- **类型**: 评估类

---

## 🎯 功能定义

**核心功能**：汇总测试报告，量化和主观评估方案带来的价值

**评估目的**：
- 验证方案的 AHA 价值（用户视角）
- 验证方案的商业 MAP 价值（商业视角）
- 发现迭代机会和问题
- 为商业决策提供依据

---

## 📊 评估维度

### 1. AHA 价值评估

#### 顿悟（Aha!）

**定义**：用户获得的新认知、新理解、新启发

**评估问题**：
- 用户在体验过程中是否有"原来可以这样！"的顿悟时刻？
- 用户是否获得了新的认知或理解？
- 用户是否改变了之前的想法或做法？
- 用户是否发现了之前没有意识到的价值？

**量化指标**：
- AHA 时刻触发率：% 的用户体验了 AHA 时刻
- AHA 时刻频率：平均每个用户体验了几次 AHA 时刻
- AHA 时刻强度：用户对 AHA 时刻的评分（1-5 分）

**主观评估**：
- 用户的反馈和引用
- 用户的表情和反应
- 用户的后续行为变化

**示例**：
```yaml
顿悟评估:
  量化指标:
    AHA_时刻触发率: "90% 的用户体验了 AHA 时刻"
    AHA_时刻频率: "平均每个用户体验了 2.3 次 AHA 时刻"
    AHA_时刻强度: "平均评分 4.5/5"

  主观评估:
    用户反馈:
      - "原来选产品可以这么简单！"
      - "AI 推荐比我想象的更准确"
      - "我以前都不知道可以这样选择"
    
    表情反应:
      - "用户在看到推荐结果时，眼睛亮了一下"
      - "用户点头，表示认可"
    
    行为变化:
      - "用户开始使用 AI 推荐，而不是自己浏览"
      - "用户向朋友推荐了这个功能"
```

#### 高光（Highlight）

**定义**：用户最满意的、印象最深的体验亮点

**评估问题**：
- 用户最满意的是什么？
- 用户印象最深的是什么？
- 用户会向朋友推荐什么？
- 用户会记住什么？

**量化指标**：
- 满意度评分：用户对功能的满意度评分（1-5 分）
- 推荐意愿：用户愿意向朋友推荐的意愿（1-5 分）
- 记忆度：用户记住的功能或特性数量

**主观评估**：
- 用户的反馈和引用
- 用户的表情和反应
- 用户的后续行为

**示例**：
```yaml
高光评估:
  量化指标:
    满意度评分: "5/5"
    推荐意愿: "5/5"
    记忆度: "平均记住 3.2 个功能"

  主观评估:
    用户反馈:
      - "推荐理由很清楚，我很放心"
      - "自然语言交互很流畅"
      - "30 秒响应，太快了"
    
    表情反应:
      - "用户在看到推荐理由时，笑了"
      - "用户表示非常满意"
    
    行为变化:
      - "用户反复使用了这个功能"
      - "用户主动探索了更多功能"
```

---

#### 进步（Progress）

**定义**：用户在效率、质量、体验等方面的提升

**评估问题**：
- 用户在效率上是否有提升？
- 用户在质量上是否有提升？
- 用户在体验上是否有提升？
- 用户是否节省了时间或成本？

**量化指标**：
- 效率提升：时间节省百分比、成本节省百分比
- 质量提升：决策质量提升、满意度提升
- 体验提升：用户体验评分提升、NPS 提升

**主观评估**：
- 用户的反馈和引用
- 用户的比较和对比
- 用户的后续行为

**示例**：
```yaml
进步评估:
  量化指标:
    效率提升:
      - "时间节省：95%"
      - "从 2 小时缩短到 5 分钟"
    
    质量提升:
      - "决策信心：从 30% 提升到 95%"
      - "满意度：从 3 分（5 分制）提升到 5 分"
    
    体验提升:
      - "NPS：从 20 提升到 70"

  主观评估:
    用户反馈:
      - "以前要花 2 小时，现在 5 分钟就搞定了"
      - "我对自己的选择更有信心了"
      - "购物变得更轻松愉快了"
    
    比较对比:
      - "比之前看评论、比价格快多了"
      - "比问朋友更专业"
    
    后续行为:
      - "用户开始频繁使用这个功能"
      - "用户向朋友推荐了这个产品"
```

### 2. 商业 MAP 价值评估

#### 潜力（Market Potential）

**定义**：市场潜力、市场规模、增长潜力

**评估问题**：
- 目标市场规模有多大？
- 市场增长率是多少？
- 市场渗透率是多少？
- 市场机会有多大？

**量化指标**：
- TAM（Total Addressable Market）：总可获得市场规模
- SAM（Serviceable Addressable Market）：可服务市场规模
- SOM（Serviceable Obtainable Market）：可获得市场规模
- 市场增长率：年增长率
- 市场渗透率：当前市场渗透率

**主观评估**：
- 市场趋势分析
- 竞争格局分析
- 宏观环境分析

**示例**：
```yaml
潜力评估:
  量化指标:
    TAM: "100 亿元"
    SAM: "10 亿元"
    SOM: "1 亿元"
    市场增长率: "30%/年"
    市场渗透率: "5%"

  主观评估:
    市场趋势:
      - "电商市场持续增长"
      - "AI 技术应用越来越广泛"
      - "用户对个性化推荐的需求增加"
    
    竞争格局:
      - "现有竞争对手：电商平台自建推荐系统"
      - "我们的优势：更中立、更智能"
    
    宏观环境:
      - "政策支持 AI 技术发展"
      - "消费者对个性化服务的接受度提高"
```

---

#### 获客（Acquisition）

**定义**：获客能力、获客成本、用户增长

**评估问题**：
- 用户如何获得？
- 获客成本是多少？
- 用户增长速度是多少？
- 用户留存率是多少？

**量化指标**：
- CAC（Customer Acquisition Cost）：获客成本
- LTV（Life Time Value）：用户生命周期价值
- LTV/CAC 比率：用户生命周期价值与获客成本的比率
- 月增长：月用户增长率
- 留存率：用户留存率（30 天、60 天、90 天）

**主观评估**：
- 获客渠道分析
- 用户增长驱动因素分析
- 用户留存驱动因素分析

**示例**：
```yaml
获客评估:
  量化指标:
    CAC: "10 元/人"
    LTV: "100 元"
    LTV_CAC_比率: "10"
    月增长: "20%"
    留存率:
      - "30 天留存率：70%"
      - "60 天留存率：50%"
      - "90 天留存率：30%"

  主观评估:
    获客渠道:
      - "电商平台合作：主要获客渠道"
      - "社交媒体推广：辅助获客渠道"
      - "口碑传播：自然增长渠道"
    
    增长驱动因素:
      - "产品价值：用户推荐率高"
      - "产品体验：用户满意度高"
      - "品牌影响：口碑传播效果好"
    
    留存驱动因素:
      - "产品价值：用户离不开"
      - "产品体验：用户体验好"
      - "用户习惯：用户形成了使用习惯"
```

---

#### 壁垒（Barrier）

**定义**：竞争优势、护城河、进入壁垒

**评估问题**：
- 有哪些竞争优势？
- 有哪些进入壁垒？
- 竞争对手可以复制吗？
- 护城河有多深？

**量化指标**：
- 技术壁垒评分：技术优势的评分（1-5 分）
- 数据壁垒评分：数据优势的评分（1-5 分）
- 品牌壁垒评分：品牌优势的评分（1-5 分）
- 网络效应评分：网络效应的评分（1-5 分）

**主观评估**：
- 竞争优势分析
- 进入壁垒分析
- 护城河深度分析

**示例**：
```yaml
壁垒评估:
  量化指标:
    技术壁垒评分: "4/5"
    数据壁垒评分: "3/5"
    品牌壁垒评分: "2/5"
    网络效应评分: "3/5"

  主观评估:
    竞争优势:
      - "技术优势：AI 算法领先"
      - "中立优势：不偏向特定商家"
      - "体验优势：用户体验更好"
    
    进入壁垒:
      - "技术壁垒：AI 算法需要大量数据和算力"
      - "数据壁垒：用户数据需要积累"
      - "网络效应：用户越多，推荐越准确"
    
    护城河深度:
      - "技术护城河：中等深度"
      - "数据护城河：中等深度"
      - "品牌护城河：浅"
      - "网络效应护城河：中等深度"
```

## 🎯 质量标准

### AHA 价值评估质量

| 指标 | 标准 |
|------|------|
| 顿悟评估 | 量化指标和主观评估都有，AHA 时刻有具体描述 |
| 高光评估 | 量化指标和主观评估都有，用户亮点有具体描述 |
| 进步评估 | 量化指标和主观评估都有，提升有具体数据支撑 |

### 商业 MAP 价值评估质量

| 指标 | 标准 |
|------|------|
| 潜力评估 | TAM/SAM/SOM 明确，有市场分析 |
| 获客评估 | CAC/LTV/LTV/CAC 比率明确，有获客和留存分析 |
| 壁垒评估 | 各壁垒评分明确，有竞争优势和进入壁垒分析 |

### 测试结论质量

| 指标 | 标准 |
|------|------|
| 四个角度 | 有效、无效、新发现、新问题四个角度都有结论 |
| 结论明确 | 结论具体明确，不是模糊描述 |
| 有依据 | 结论有测试数据或观察记录支撑 |

### 迭代方向质量

| 指标 | 标准 |
|------|------|
| 优先级明确 | 高、中、低优先级分类明确 |
| 方向具体 | 迭代方向具体，不是模糊描述 |
| 可执行 | 迭代方向可执行，资源可获得 |
