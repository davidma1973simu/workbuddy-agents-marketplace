# NCO_Crosslinker - 新酷界外交叉激发器

## Skill 概述

**Skill ID**: `NCO_Crosslinker`
**名称**: 新酷界外交叉激发器
**所属Agent**: Inspire Specialist (启发师)
**任务类型**: 创意生成

## 功能描述

强制生成"新、酷、界外"（NCO - New, Cool, Out of the Box）的灵感源，并与最佳HMW创新机遇进行交叉激发，生成20-30个全新的创意想法。

## 核心能力

1. **NCO灵感源生成**：从New、Cool、Out of the Box三个类别生成丰富灵感源
2. **交叉激发**：将灵感源与HMW机遇进行创意交叉
3. **创意多样化**：确保创意覆盖不同类型的灵感源
4. **创意数量保证**：生成20-30个高质量创意想法

## 交叉激发方法

### 1. 技术移植

**定义**：将A领域的技术应用到B问题

**示例**：
```
灵感源：AI大语言模型（GPT）
HMW：How might we 利用AI预测用户需求，在他们需要之前就推荐？

交叉：
- 技术移植 → "用GPT对话式推荐，像朋友聊天一样推荐产品"
- 技术移植 → "用GPT生成个性化产品描述，讲述产品故事"
```

### 2. 模式借鉴

**定义**：参考C行业的成功模式

**示例**：
```
灵感源：Netflix的"为你推荐"
HMW：How might we 重塑产品选择的体验，让过程本身成为一种享受？

交叉：
- 模式借鉴 → "像Netflix推荐电影一样推荐产品，个性化主页"
- 模式借鉴 → "像Netflix的'继续观看'，记住用户上次的选择"
```

### 3. 概念融合

**定义**：将X概念和Y需求结合

**示例**：
```
灵感源：游戏化（积分系统）
HMW：How might we 重塑产品选择的体验，让过程本身成为一种享受？

交叉：
- 概念融合 → "购物获得积分，积分可以兑换商品或特权"
- 概念融合 → "浏览商品就像玩游戏，完成挑战获得奖励"
```

### 4. 逆向思维

**定义**：反常规的思考方式

**示例**：
```
灵感源：传统推荐（用户找商品）
HMW：How might we 利用AI预测用户需求，在他们需要之前就推荐？

交叉：
- 逆向思维 → "不是用户找商品，而是商品找用户（主动推送）"
- 逆向思维 → "不是推荐热门商品，而是推荐冷门但合适的商品"
```

## 创意生成流程

### 步骤1：生成灵感源（NCO）

- **New**：选择5-8个新兴技术和趋势
- **Cool**：选择5-8个创新模式和体验
- **Out of the Box**：选择5-8个跨领域灵感

### 步骤2：交叉激发

对每个灵感源和每个最佳HMW机遇进行交叉：

```
for 每个灵感源 in [New, Cool, Out of the Box]:
  for 每个HMW机遇 in 最佳HMW机遇列表:
    使用交叉激发方法（技术移植/模式借鉴/概念融合/逆向思维）
    生成1-2个创意想法
```

确保：
- 每个HMW机遇至少生成8-10个创意
- 每种灵感源类型（New/Cool/Out of the Box）至少生成6-8个创意
- 总创意数量：20-30个

### 步骤3：创意表述

每个创意需要包含：
- **创意想法**：清晰、简洁、可理解的表述
- **灵感源**：具体来源（如"New - AI/大语言模型"）
- **交叉方式**：技术移植/模式借鉴/概念融合/逆向思维
- **相关HMW**：关联的HMW机遇

## 技术实现要点

### NCO灵感源数据库

建立NCO灵感源数据库，包含：
- New：50+ 新兴技术和趋势
- Cool：50+ 创新模式和体验
- Out of the Box：50+ 跨领域灵感

### 交叉激发算法

1. **灵感源选择**：从数据库中随机或按需选择灵感源
2. **HMW映射**：将灵感源与HMW机遇进行匹配
3. **交叉生成**：应用交叉激发方法生成创意
4. **创意表述**：规范化创意表述
5. **多样性保证**：确保创意来源和类型的多样性

### 创意质量控制

- 去重：避免重复创意
- 相关性检查：确保创意与HMW相关
- 新颖性检查：确保创意有创新性
- 可行性标注：标注创意的可行性（可选）
