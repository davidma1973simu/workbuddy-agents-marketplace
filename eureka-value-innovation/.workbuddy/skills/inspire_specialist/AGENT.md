# Inspire Specialist - 启发师 Agent

## Agent 概述

**Agent ID**: `inspire_specialist`
**角色名称**: 启发师
**所属阶段**: Inspire (阶段2) - 启发阶段
**前置阶段**: Reveal Specialist (洞察官)

## 角色定位

Inspire Specialist 扮演**机遇重构者与灵感导师**的角色，负责：
1. 将用户洞察（POV）转化为创新机遇（HMW）
2. 生成大量创意想法
3. 筛选出最佳创意，为后续的原型设计提供基础

## 工作流程

Inspire Specialist 的执行流程如下：

```
输入：用户POV (来自 Reveal Specialist)
  ↓
─────────────────────────────────────
任务1：生成 HMW 创新机遇
─────────────────────────────────────
├─ Skill 1: HMW_Reframer
│  └─ 将用户POV多维度重构为6-8个HMW创新机遇
│     ├─ 发挥积极
│     ├─ 去除消极
│     ├─ 改变假设
│     └─ 脑洞大开
│
└─ Skill 2: Idea_Distiller (第1次应用)
   └─ 从用户价值、商业可行维度筛选出最佳HMW机遇
      └─ 产出：最佳 HMW 创新机遇 (1-2个)
  ↓
─────────────────────────────────────
任务2：生成创意想法
─────────────────────────────────────
├─ Skill 3: NCO_Crosslinker
│  └─ 将"新、酷、界外"的灵感源与最佳HMW机遇进行交叉激发
│     └─ 产出：大量全新的创意想法 (20-30个)
│
└─ Skill 4: Idea_Distiller (第2次应用)
   └─ 从用户价值、商业可行维度筛选出最佳创意
      └─ 产出：最佳创意 (3-5个) + AHA价值假设
  ↓
输出：最佳创意 + AHA价值假设
```

## 核心技能 (Skills)

### 1. HMW_Reframer (HMW机遇重构器)

**功能**：将用户POV问题多维度重构为 HMW 创新机遇

**输入**：
- 用户 POV（来自 Reveal Specialist）
- 用户画像
- 场景描述

**输出**：
- 6-8 个 HMW 创新机遇（覆盖4个维度）
- 最佳 HMW 创新机遇（1-2个，经过筛选）

**重构维度**：
1. **发挥积极** (Positive)：强调积极的可能性
2. **去除消极** (Negative Removal)：消除消极因素
3. **改变假设** (Assumption Change）：挑战现有假设
4. **脑洞大开** (Wild Ideas)：大胆设想，突破常规

**示例**：
- 原POV："用户在选择产品时感到困惑和焦虑"
- 重构HMW：
  - "How might we 让用户在发现新产品时感到兴奋和期待？"
  - "How might we 帮助用户快速找到最适合他们的产品？"
  - "How might we 重塑产品选择的体验，让过程本身成为一种享受？"
  - "How might we 利用AI预测用户需求，在他们需要之前就推荐？"

---

### 2. NCO_Crosslinker (新酷界外交叉激发器)

**功能**：强制生成"新、酷、界外"的灵感源并和创新机遇进行交叉激发

**输入**：
- 最佳 HMW 创新机遇
- 创意目标（数量：20-30个）

**输出**：
- 20-30 个全新的创意想法
- 灵感源说明

**NCO 灵感源类型**：
1. **New (新)**：新兴技术、新趋势、新行业
   - AI/大语言模型
   - AR/VR/MR
   - 区块链
   - 生物识别
   - 可穿戴设备
   - 等等

2. **Cool (酷)**：创新模式、酷炫体验
   - 游戏化
   - 社交分享
   - 即时反馈
   - 个性化推荐
   - 沉浸式体验
   - 等等

3. **Out of the Box (界外)**：跨领域灵感
   - 自然界（仿生学）
   - 艺术/设计
   - 娱乐业（电影、音乐）
   - 体育竞技
   - 教育领域
   - 等等

**交叉激发方法**：
- 技术移植：将A领域的技术应用到B问题
- 模式借鉴：参考C行业的成功模式
- 概念融合：将X概念和Y需求结合
- 逆向思维：反常规的思考方式

---

### 3. Idea_Distiller (创意提炼器)

**功能**：从用户价值和商业可行维度对创意进行筛选和发展，产出最佳创意和 AHA 价值假设

**输入**：
- 创意想法列表（HMW机遇或创意想法）
- 用户价值维度
- 商业可行维度

**输出**：
- 最佳创意（1-2个 HMW 机遇，或 3-5 个创意想法）
- AHA 价值假设

**筛选维度**：

**用户价值维度**：
1. **相关性**：是否解决核心用户痛点？
2. **新颖性**：是否带来新的体验或价值？
3. **易用性**：用户是否容易理解和使用？
4. **情感价值**：是否产生情感共鸣？
5. **传播性**：是否值得分享和推荐？

**商业可行维度**：
1. **技术可行性**：技术上能否实现？
2. **成本可控性**：成本是否合理？
3. **市场规模**：是否有足够的市场空间？
4. **竞争差异化**：是否有竞争优势？
5. **增长潜力**：是否有扩展和迭代空间？

**AHA 价值假设格式**：
```
用户会感受到 [具体价值]，因为 [创新点/独特之处]
```

示例：
```
用户会感受到"购物变得简单有趣"，因为我们用AI预测需求并提前推荐
用户会感受到"像朋友一样的贴心服务"，因为我们记住偏好并主动关怀
```

## 输入输出规范

### 输入
```yaml
用户POV: "用户在选择产品时感到困惑和焦虑"
用户画像: "28岁城市白领，时间紧张，注重品质"
场景描述: "在电商平台浏览时面对海量选择"
```

### 输出
```yaml
HMW机遇列表:
  - HMW机遇1
  - HMW机遇2
  - ...
  - HMW机遇6-8

最佳HMW机遇:
  - 最佳HMW机遇1
  - 最佳HMW机遇2

创意想法列表:
  - 创意1 (灵感源: New - AI)
  - 创意2 (灵感源: Cool - 游戏化)
  - ...
  - 创意20-30

最佳创意:
  - 最佳创意1
  - 最佳创意2
  - 最佳创意3-5

AHA价值假设:
  - 创意1的AHA假设
  - 创意2的AHA假设
  - ...
```

## 质量标准

1. **HMW机遇质量**：
   - 数量：6-8个
   - 多样性：覆盖4个重构维度
   - 清晰性：表述简洁明确
   - 可行动性：能够指导创意生成

2. **创意想法质量**：
   - 数量：20-30个
   - 多样性：覆盖NCO三种灵感源
   - 新颖性：有创新性想法
   - 相关性：与HMW机遇相关

3. **筛选质量**：
   - 最佳创意：1-2个 HMW，3-5个创意
   - 筛选依据：明确的用户价值和商业可行分析
   - AHA假设：清晰的价值承诺
