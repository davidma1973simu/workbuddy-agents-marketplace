# Storyboard_Scriptor - 故事板编剧

## 📋 基本信息

- **Skill ID**: `Storyboard_Scriptor`
- **Skill 名称**: 故事板编剧
- **所属 Agent**: Shape Specialist（架构师）
- **版本**: v1.0.0
- **类型**: 创意类

---

## 🎯 功能定义

**核心功能**：将概念方案转化为用户视角体验的 6 幕体验故事脚本

**体验故事目的**：
- 可视化用户旅程
- 理解用户真实体验
- 发现体验中的机会和问题
- 为原型设计提供场景基础

---

## 🎬 6 幕体验故事

### 幕次结构

| 幕次 | 名称 | 内容 | 目的 |
|------|------|------|------|
| 第 1 幕 | 用户问题 | 用户面临的问题和痛点 | 建立背景，引发共鸣 |
| 第 2 幕 | POV | 用户的观点、感受和期望 | 理解用户内心世界 |
| 第 3 幕 | 接触新方案 | 用户如何接触和了解新方案 | 展示方案触达路径 |
| 第 4 幕 | 使用新方案解决问题 | 用户如何使用方案解决问题 | 展示核心价值 |
| 第 5 幕 | 得到方案的结果 | 用户获得的结果和效果 | 证明价值，量化效果 |
| 第 6 幕 | 用户的感受和所思所想 | 用户的情感反应和内心想法 | 强化情感连接 |

---

### 第 1 幕：用户问题

**内容要求**：
- 具体描述用户面临的场景和问题
- 展示问题的严重性和紧迫性
- 引起用户的共鸣
- 为后续的解决方案铺垫

**格式**：
```yaml
场景描述: "[场景描述]"
用户行为: "[用户行为]"
用户感受: "[用户感受]"
关键画面: "[关键画面描述]"
```

**示例**：
```yaml
场景描述: "周五晚上 9 点，小明在电商平台上浏览了 2 小时，想要买一台新的笔记本电脑，但是面对上百个产品，不知道选哪个，感到焦虑和困惑。"

用户行为: "- 不断刷新页面，查看产品详情\n- 对比多个产品，但仍然无法决定\n- 查看评价，但评价褒贬不一\n- 关掉页面，但过一会儿又打开"

用户感受: "- 焦虑：担心选错了，浪费钱\n- 困惑：信息太多，不知道信哪个\n- 疲惫：浏览了 2 小时，仍然没有结果\n- 沮丧：周末本来想好好休息，结果浪费了时间"

关键画面: "- 小明坐在电脑前，眉头紧锁\n- 电脑屏幕上显示着多个产品页面\n- 时钟指向 9 点，小明显得疲惫不堪"
```

---

### 第 2 幕：POV

**内容要求**：
- 表达用户的观点、感受和期望
- 展示用户的内心世界
- 反映用户的核心需求
- 为后续的解决方案提供依据

**格式**：
```yaml
用户观点: "[用户观点]"
用户感受: "[用户感受]"
用户期望: "[用户期望]"
内心独白: "[用户的内心想法]"
```

**示例**：
```yaml
用户观点: "选产品太难了，信息太多，不知道怎么选。如果有个人能帮我推荐就好了。"

用户感受: "- 无力：感觉自己做不好选择\n- 期望：希望有可靠的建议\n- 信任：愿意相信专业的推荐"

用户期望: "- 希望有一个懂我的朋友帮我推荐\n- 希望推荐是客观中立的\n- 希望推荐能解释为什么推荐这个\n- 希望整个过程简单快速"

内心独白: "如果有个懂我的朋友就好了，他了解我的需求，能帮我推荐最适合的笔记本电脑。那样我就能节省很多时间，也不用在这么多选择中纠结了。"
```

---

### 第 3 幕：接触新方案

**内容要求**：
- 展示用户如何接触和了解新方案
- 描述第一次使用方案的体验
- 突出方案的易用性
- 引起用户的兴趣

**格式**：
```yaml
接触场景: "[接触场景描述]"
用户行为: "[用户行为]"
用户感受: "[用户感受]"
关键画面: "[关键画面描述]"
```

**示例**：
```yaml
接触场景: "小明的注意力被商品页面上的一个小图标吸引，上面写着'让 ShopMate AI 帮你选择'。小明有点好奇，决定点击尝试一下。"

用户行为: "- 点击 ShopMate AI 图标\n- 弹出一个对话框，提示：'告诉我你的需求，我来帮你选择'\n- 小明试着输入：'我要买个 4000 元左右的笔记本电脑，用来办公和看电影'"

用户感受: "- 好奇：这个 AI 到底能做什么？\n- 期待：希望能得到有用的建议\n- 放松：不需要自己费劲对比了"

关键画面: "- 商品页面上的 ShopMate AI 图标\n- 弹出的对话框\n- 小明输入需求时的表情"
```

---

### 第 4 幕：使用新方案解决问题

**内容要求**：
- 展示用户如何使用方案解决问题
- 突出方案的核心功能和价值
- 展示方案的易用性和高效性
- 让用户感受到方案的优秀

**格式**：
```yaml
使用过程: "[使用过程描述]"
用户行为: "[用户行为]"
用户感受: "[用户感受]"
关键画面: "[关键画面描述]"
AHA 时刻: "[用户获得的价值]"
```

**示例**：
```yaml
使用过程: "小明输入需求后，不到 30 秒，AI 就给出了回应：'根据您的需求，我为您推荐 3 款笔记本电脑'。每款推荐都有一个推荐理由，小明可以点击查看详细对比。"

用户行为: "- 查看 AI 的推荐\n- 阅读推荐理由，了解为什么推荐这些\n- 点击查看产品对比\n- 问了一个问题：'哪个最适合办公？'AI 立即回答"

用户感受: "- 惊喜：AI 推荐很专业，理由很充分\n- 轻松：不需要自己费劲对比了\n- 信任：AI 的解释很透明，不是黑箱\n- 满意：推荐的几款都符合我的需求"

关键画面: "- AI 回复的界面\n- 推荐产品和理由\n- 小明满意地点头"

AHA 时刻: "原来选产品可以这么简单！就像有个懂我的朋友帮我推荐一样。"
```

---

### 第 5 幕：得到方案的结果

**内容要求**：
- 展示用户获得的结果和效果
- 量化方案的价值
- 证明方案的有效性
- 强化用户的满意度

**格式**：
```yaml
结果描述: "[结果描述]"
量化指标: "[量化指标]"
用户行为: "[用户行为]"
用户感受: "[用户感受]"
关键画面: "[关键画面描述]"
```

**示例**：
```yaml
结果描述: "小明根据 AI 的推荐，选择了一款笔记本电脑。整个过程只用了 5 分钟，比之前浏览了 2 小时还要高效。小明对自己的选择很有信心，觉得这是最适合他的产品。"

量化指标:
  - "时间节省：从 2 小时缩短到 5 分钟，节省了 95% 的时间"
  - "决策信心：从 30% 提升到 95%"
  - "满意度：从 3 分（5 分制）提升到 5 分"

用户行为: "- 点击购买\n- 收到确认邮件，感到安心\n- 关闭页面，心情轻松"

用户感受: "- 轻松：终于解决了选择困难\n- 满意：对自己的选择很有信心\n- 高兴：节省了时间，可以做其他事情\n- 感激：ShopMate AI 帮了大忙"

关键画面: "- 小明点击购买\n- 小明关掉页面，伸了个懒腰\n- 时钟指向 9:05，只用了 5 分钟"
```

### 第 6 幕：用户的感受和所思所想

**内容要求**：
- 展示用户的情感反应和内心想法
- 强化用户的满意度和忠诚度
- 表达用户的推荐意愿
- 为方案的口碑传播奠定基础

**格式**：
```yaml
情感反应: "[情感反应]"
内心想法: "[用户的内心想法]"
行为意向: "[用户的行为意向]"
推荐意愿: "[用户的推荐意愿]"
关键画面: "[关键画面描述]"
```

**示例**：
```yaml
情感反应: "- 释然：终于不用再纠结了\n- 开心：周末终于可以好好休息了\n- 感激：ShopMate AI 真的很有用\n- 信任：以后选产品都会用它"

内心想法: "太棒了！以后再也不用为选择发愁了。ShopMate AI 就像我身边的一个智能助手，随时帮我做选择。我要告诉我的朋友们，让他们也试试。"

行为意向: "- 下次购物还会使用 ShopMate AI\n- 会推荐给朋友和家人\n- 会关注 ShopMate AI 的更新和优化"

推荐意愿: "强烈推荐，评分 5 星。"

关键画面: "- 小明坐在沙发上，拿着手机给朋友发消息\n- 小明的表情轻松愉快\n- 屏幕上显示：'试试这个 ShopMate AI，超好用！'"
```

## 🎯 质量标准

### 故事完整性

| 指标 | 标准 |
|------|------|
| 幕次完整性 | 6 幕都完整呈现 |
| 内容完整性 | 每幕包含所有必需的内容元素 |
| 故事连贯性 | 6 幕之间逻辑连贯，形成完整故事 |

### 用户真实性

| 指标 | 标准 |
|------|------|
| 行为真实性 | 用户行为真实可信，符合用户画像 |
| 感受真实性 | 用户感受真实，符合场景和心理 |
| 对话真实性 | 用户对话自然，符合语言习惯 |
| 心理真实性 | 用户心理变化合理，符合人性 |

### 场景具体性

| 指标 | 标准 |
|------|------|
| 场景描述 | 场景描述具体，有画面感 |
| 时间地点 | 时间地点明确，增加真实感 |
| 细节丰富 | 细节丰富，增强沉浸感 |
| 关键画面 | 每幕都有关键画面，易于可视化 |

### 情感连贯性

| 指标 | 标准 |
|------|------|
| 情感变化 | 情感变化连贯自然，有起伏 |
| 情感逻辑 | 情感变化有逻辑，符合剧情发展 |
| 情感深度 | 情感有深度，不只是表面感受 |
| 情感共鸣 | 能引起用户共鸣 |

### 价值体现性

| 指标 | 标准 |
|------|------|
| AHA 价值 | AHA 价值在故事中得到明确体现 |
| 价值量化 | 价值量化明确，有具体指标 |
| 价值对比 | 价值对比清晰，突出方案优势 |
| 价值传递 | 价值传递有效，用户能理解 |

### 可视化性

| 指标 | 标准 |
|------|------|
| 画面描述 | 画面描述清晰，易于绘制 |
| 场景转换 | 场景转换自然，易于分镜 |
| 视觉焦点 | 视觉焦点明确，易于突出重点 |
| 故事板结构 | 故事板结构清晰，易于呈现 |
