# Eureka 价值创新产品 - Agents 快速使用指南

## 📋 概述

Eureka 价值创新产品由 4 个 Sub-Agents 组成，每个 Agent 负责创新过程的一个阶段。它们可以单独使用，也可以整合使用完成整个价值创新流程。

---

## 🎯 四个 Agents 总览

| Agent | 阶段 | 角色 | Skills 数量 | 主要职责 |
|-------|------|------|-------------|----------|
| Reveal Specialist | Reveal (阶段1) | 洞察官 | 2 | 探索用户旅程，挖掘洞察，生成 POV |
| Inspire Specialist | Inspire (阶段2) | 启发师 | 3 | 生成 HMW 机遇，创意想法，筛选最佳创意 |
| Shape Specialist | Shape (阶段3) | 架构师 | 3 | 方案拷问，方案构建，体验故事设计 |
| Exam Specialist | Exam (阶段4) | 验证官 | 4 | 测试验证，价值评估，方案呈现，落地规划 |

---

## 🔧 单独使用指南

### 1. Reveal Specialist - 洞察官

#### 何时使用

- 需要探索用户旅程
- 需要挖掘用户洞察
- 需要生成 POV (Point of View)

#### 调用方式

```bash
# 快速使用
使用 Reveal Specialist 分析用户旅程：用户场景：[描述用户使用产品/服务的场景]

# 完整使用
使用 Reveal Specialist 分析：
项目简报：[项目简报内容]
用户画像：[用户画像内容]
目标场景：[目标使用场景]
```

#### 输入要求

**必需输入**：
- 项目简报：简要描述项目背景和目标
- 用户画像：描述目标用户的基本信息和特征
- 目标场景：想要分析的使用场景

**可选输入**：
- 现有数据：已有的用户行为数据、反馈数据等
- 竞品分析：竞争对手的相关信息

#### 输出内容

- 用户旅程图：用户在场景中的行为、感受、痛点
- 用户洞察：基于 FIND 模型挖掘的深层洞察
- POV (Point of View)：用户观点声明
- 利益相关者分析：各利益相关者的角色、诉求、影响

#### 快速示例

```bash
使用 Reveal Specialist 分析用户旅程：
项目简报：为电商平台设计智能购物助手
用户画像：28 岁城市白领，时间紧张，注重品质
目标场景：在电商平台浏览时面对海量选择，不知道选哪个
```

---

### 2. Inspire Specialist - 启发师

#### 何时使用

- 已经有了用户洞察和 POV
- 需要生成创新机遇（HMW）
- 需要生成创意想法
- 需要筛选最佳创意

#### 调用方式

```bash
# 快速使用
使用 Inspire Specialist 生成创意：POV：[用户的观点声明]

# 完整使用
使用 Inspire Specialist 生成：
POV：[用户的观点声明]
用户画像：[用户画像内容]
利益相关者分析：[利益相关者分析内容]
AHA 价值假设：[AHA 价值假设内容]
```

#### 输入要求

**必需输入**：
- POV：用户的观点声明，来自 Reveal Specialist

**推荐输入**：
- 用户画像：来自 Reveal Specialist
- 利益相关者分析：来自 Reveal Specialist
- AHA 价值假设：初步的价值假设

#### 输出内容

- HMW 机遇列表：基于 POV 生成的创新机遇
- 创意想法列表：基于 HMW 机遇和 NCO 灵感源生成的创意
- 最佳创意：经过评估和筛选的 1-3 个最佳创意
- 创意评分：用户价值评分和商业可行评分

#### 快速示例

```bash
使用 Inspire Specialist 生成创意：
POV：28 岁的城市白领在选择产品时感到困惑和焦虑，"如果有个人能帮我推荐就好了"
用户画像：时间紧张，注重品质，对技术有一定了解但不是专家
利益相关者分析：用户需要快速找到适合的产品，商家需要提高转化率
AHA 价值假设：用户可以在 5 分钟内找到最适合自己的产品
```

### 3. Shape Specialist - 架构师

#### 何时使用

- 已经有了最佳创意
- 需要对创意进行拷问和压力测试
- 需要构建完整的概念方案
- 需要设计用户体验故事

#### 调用方式

```bash
# 快速使用
使用 Shape Specialist 构建方案：
最佳创意：[最佳创意内容]
AHA 价值假设：[AHA 价值假设]

# 完整使用
使用 Shape Specialist 构建：
最佳创意：
  - 创意名称：[创意名称]
    描述：[创意描述]
    AHA 价值假设：[AHA 价值假设]
    用户价值评分：[评分]
    商业可行评分：[评分]

利益相关者分析：
  - 用户：[用户分析]
  - 商家：[商家分析]
  - 平台：[平台分析]

用户画像：[用户画像内容]
使用场景：[使用场景描述]
```

#### 输入要求

**必需输入**：
- 最佳创意：来自 Inspire Specialist 的最佳创意
- AHA 价值假设：创意的价值假设
- 利益相关者分析：来自 Reveal Specialist

**推荐输入**：
- 用户画像：来自 Reveal Specialist
- 使用场景：来自 Reveal Specialist

#### 输出内容

- 拷问报告：从用户、技术、商业、利益方四个维度对创意进行拷问
- 概念方案：完整的方案设计，包括概念名称、核心价值、核心功能、关键特性、技术架构、商业逻辑、利益方关系、实施路径
- 体验故事脚本：6 幕体验故事（用户问题、POV、接触新方案、使用新方案解决问题、得到方案的结果、用户的感受和所思所想）

#### 快速示例

```bash
使用 Shape Specialist 构建方案：
最佳创意：
  - 创意名称："AI 智能购物助手"
    描述："基于 AI 的个性化产品推荐和决策支持系统"
    AHA 价值假设："用户可以在 5 分钟内找到最适合自己的产品"
    用户价值评分：4.5/5
    商业可行评分：4.2/5

利益相关者分析：
  - 用户：快速找到适合的产品
  - 商家：提高转化率
  - 平台：提高用户粘性

用户画像：28 岁城市白领，时间紧张，注重品质
使用场景：在电商平台浏览时面对海量选择，不知道选哪个
```

### 4. Exam Specialist - 验证官

#### 何时使用

- 已经有了概念方案和体验故事
- 需要对方案进行测试验证
- 需要评估方案的价值
- 需要生成投资者呈现脚本
- 需要制定迭代计划和商业模式

#### 调用方式

```bash
# 快速使用
使用 Exam Specialist 验证方案：
概念方案：[概念方案内容]
体验故事：[体验故事内容]

# 完整使用
使用 Exam Specialist 验证：
概念方案：
  概念名称：[概念名称]
  核心价值：[核心价值]
  核心功能：[核心功能列表]
  关键特性：[关键特性列表]

体验故事：[6 幕体验故事内容]

项目简报：[项目简报内容]
POV：[用户的观点声明]

测试数据：[可选：已有的测试数据和用户反馈]
```

#### 输入要求

**必需输入**：
- 概念方案：来自 Shape Specialist 的完整概念方案
- 体验故事：来自 Shape Specialist 的 6 幕体验故事
- 项目简报：来自 Reveal Specialist 的项目简报
- POV：来自 Reveal Specialist 的用户观点声明

**可选输入**：
- 测试数据：已有的测试数据和用户反馈
- 观察记录：用户测试过程中的观察记录
- 量化指标：可量化的测试指标

#### 输出内容

- 测试报告：包含测试汇总、AHA 价值评估（顿悟、高光、进步）、商业 MAP 价值评估（潜力、获客、壁垒）、迭代方向
- 电梯呈现脚本：60 秒投资者呈现脚本
- 迭代计划：30-60-90 天项目迭代计划
- 商业模式画布：9 要素商业模式画布

#### 快速示例

```bash
使用 Exam Specialist 验证方案：
概念方案：
  概念名称："ShopMate AI"
  核心价值："让购物决策变得简单、快速、可靠，在 5 分钟内找到最适合自己的产品"
  核心功能：智能问答、个性化推荐、对比分析、购买决策

体验故事：
  第 1 幕：用户面临的选择困难
  第 2 幕：用户的期望和观点
  第 3 幕：接触 ShopMate AI
  第 4 幕：使用 ShopMate AI 解决问题
  第 5 幕：得到满意的结果
  第 6 幕：用户的感受和推荐意愿

项目简报：为电商平台设计智能购物助手
POV：28 岁的城市白领在选择产品时感到困惑和焦虑，"如果有个人能帮我推荐就好了"
```

## 📝 完整示例

### 示例项目：智能购物助手

#### 项目简报
为电商平台设计智能购物助手，帮助用户快速找到最适合自己的产品

#### 用户画像
- 年龄：28 岁
- 职业：城市白领
- 特征：时间紧张，注重品质，对技术有一定了解但不是专家

#### 目标场景
在电商平台浏览时面对海量选择，想要买一台笔记本电脑，但不知道选哪个

---

#### 步骤 1：Reveal - 洞察

**调用**：
```bash
使用 Reveal Specialist 分析：
项目简报：为电商平台设计智能购物助手
用户画像：28 岁城市白领，时间紧张，注重品质
目标场景：在电商平台浏览时面对海量选择，不知道选哪个
```

**输出**：
- 用户旅程图：浏览 → 对比 → 纠结 → 疲惫 → 放弃
- 用户洞察：用户选择产品时面临信息过载，缺乏决策支持，"如果有个人能帮我推荐就好了"
- POV：28 岁的城市白领在选择产品时感到困惑和焦虑，"如果有个人能帮我推荐就好了"
- 利益相关者分析：
  - 用户：需要快速找到适合的产品
  - 商家：需要提高转化率
  - 平台：需要提高用户粘性

---

#### 步骤 2：Inspire - 启发

**调用**：
```bash
使用 Inspire Specialist 生成：
POV：28 岁的城市白领在选择产品时感到困惑和焦虑，"如果有个人能帮我推荐就好了"
用户画像：时间紧张，注重品质，对技术有一定了解但不是专家
利益相关者分析：用户需要快速找到适合的产品，商家需要提高转化率，平台需要提高用户粘性
AHA 价值假设：用户可以在 5 分钟内找到最适合自己的产品
```

**输出**：
- HMW 机遇：
  - HMW 为用户提供个性化的产品推荐？
  - HMW 让用户快速做出购买决策？
  - HMW 让用户相信推荐的结果？
- 创意想法：
  - AI 智能购物助手
  - 社区推荐系统
  - 专家咨询平台
- 最佳创意：AI 智能购物助手
  - 描述："基于 AI 的个性化产品推荐和决策支持系统"
  - AHA 价值假设："用户可以在 5 分钟内找到最适合自己的产品"
  - 用户价值评分：4.5/5
  - 商业可行评分：4.2/5

#### 步骤 3：Shape - 构建

**调用**：
```bash
使用 Shape Specialist 构建：
最佳创意：
  - 创意名称："AI 智能购物助手"
    描述："基于 AI 的个性化产品推荐和决策支持系统"
    AHA 价值假设："用户可以在 5 分钟内找到最适合自己的产品"
    用户价值评分：4.5/5
    商业可行评分：4.2/5

利益相关者分析：
  - 用户：快速找到适合的产品
  - 商家：提高转化率
  - 平台：提高用户粘性

用户画像：28 岁城市白领，时间紧张，注重品质
使用场景：在电商平台浏览时面对海量选择，不知道选哪个
```

**输出**：
- 拷问报告：从用户、技术、商业、利益方四个维度拷问，主要风险包括用户信任、数据质量、竞争风险
- 概念方案：
  - 概念名称："ShopMate AI"
  - 核心价值："让购物决策变得简单、快速、可靠，在 5 分钟内找到最适合自己的产品"
  - 核心功能：智能问答、个性化推荐、对比分析、购买决策
  - 关键特性：自然语言理解、推荐理由透明、多轮对话等
  - 技术架构：前端（Web + 移动）、后端（API 网关 + 业务逻辑 + 推荐引擎）、AI 模型（NLU + 推荐算法 + 用户画像）、数据层（产品数据库 + 用户数据库 + 行为日志）
  - 商业逻辑：B2B2C 模式，按使用量收费（0.01 元/次推荐）和按效果收费（佣金率 2-5%）
  - 利益方关系：用户获得快速决策，商家获得提高转化率，平台获得技术服务费
  - 实施路径：MVP 开发（3 个月）→ 产品迭代（3 个月）→ 市场推广（6 个月）
- 体验故事脚本：6 幕体验故事，从用户的焦虑和困惑开始，到最终轻松满意地完成购买

---

#### 步骤 4：Exam - 验证

**调用**：
```bash
使用 Exam Specialist 验证：
概念方案：
  概念名称："ShopMate AI"
  核心价值："让购物决策变得简单、快速、可靠，在 5 分钟内找到最适合自己的产品"
  核心功能：智能问答、个性化推荐、对比分析、购买决策

体验故事：[6 幕体验故事]

项目简报：为电商平台设计智能购物助手
POV：28 岁的城市白领在选择产品时感到困惑和焦虑，"如果有个人能帮我推荐就好了"
```

**输出**：
- 测试报告：
  - AHA 价值评估：
    - 顿悟：用户获得"原来选产品可以这么简单"的新认知
    - 高光：30 秒内快速响应是最满意的体验
    - 进步：时间节省 95%，决策信心提升 65%，满意度从 3 分提升到 5 分
  - 商业 MAP 价值评估：
    - 潜力：目标市场规模约 100 亿元
    - 获客：按使用量收费和按效果收费相结合，易于获客
    - 壁垒：算法效果和用户体验形成竞争优势
  - 迭代方向：增强用户信任（提供推荐理由）、建立数据质量监控机制、明确差异化竞争优势

- 电梯呈现脚本（60 秒）：
  ```
  电商购物面临信息过载，28 岁的白领平均花费 2 小时才能做出决策（10 秒）。
  
  ShopMate AI 是一款智能购物助手，让用户在 5 分钟内找到最适合自己的产品（15 秒）。
  
  测试结果显示：时间节省 95%，决策信心提升 65%，用户满意度从 3 分提升到 5 分（15 秒）。
  
  目标市场规模约 100 亿元，我们的算法效果和用户体验形成竞争优势（10 秒）。
  
  我们正在寻求融资，用于技术迭代和市场推广，一起打造电商购物的新体验（10 秒）。
  ```

- 迭代计划：
  - 30 天计划（快速验证阶段）：完成 MVP，验证核心功能，目标：功能完成度 100%，测试通过率 > 90%，用户满意度 > 4/5
  - 60 天计划（功能完善阶段）：功能完善，用户增长，目标：用户数 > 1000，日活跃率 > 30%，用户满意度 > 4.5/5
  - 90 天计划（规模化阶段）：规模化，商业化，目标：用户数 > 5000，收入 > 10 万，用户满意度 > 4.5/5

- 商业模式画布（9 要素）：
  - 客户细分：电商平台、终端用户
  - 价值主张：为电商平台提供智能推荐服务，为终端用户提供快速决策支持

## 📞 常见问题

### Q1：我需要使用所有的 Agents 吗？

A：不需要。你可以根据需要单独使用某个 Agent，也可以整合使用所有 Agents。例如：
- 如果只需要用户洞察，只需使用 Reveal Specialist
- 如果已经有了洞察，只需要生成创意，只需使用 Inspire Specialist
- 如果要进行完整的创新项目，建议整合使用所有 Agents

### Q2：我可以跳过某个 Agent 吗？

A：可以。如果你已经有了某个 Agent 的输出，可以直接跳过该 Agent，使用下一个 Agent。例如：
- 如果你已经有了最佳创意，可以直接使用 Shape Specialist
- 如果你已经有了概念方案，可以直接使用 Exam Specialist

### Q3：整合使用需要多长时间？

A：整合使用的时间取决于项目的复杂度和输入信息的详细程度。一般来说：
- 简单项目：1-2 小时
- 中等复杂度项目：3-4 小时
- 复杂项目：5-8 小时

### Q4：如何保证输出质量？

A：以下是保证输出质量的方法：
- 提供详细准确的输入信息
- 参考快速使用示例，了解输入格式
- 查看每个 Agent 的 Skill 定义，了解质量标准
- 迭代优化：如果输出不满意，可以重新执行

### Q5：如何保存和传递数据？

A：建议使用以下方法保存和传递数据：
- 创建一个项目文件夹
- 每次调用后保存输出到独立的文件
- 使用明确的文件命名，如 `reveal_output.md`、`inspire_output.md` 等
- 在下一次调用时，复制粘贴相关的输出内容
