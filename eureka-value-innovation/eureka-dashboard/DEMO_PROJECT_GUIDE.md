# Eureka 示范项目使用指南

## 项目概述

这是一个完整的示范项目，展示了如何使用 Eureka RISE 方法论解决**20-35岁都市白领女性在鞋服门店购物时的认知过载问题**。

### 项目主题

**智能社交购物助手**

- **目标用户**：20-35岁都市白领女性，无锻炼习惯，有活力和社交展示需求
- **核心痛点**：面对鞋服门店内款式众多，认知过载，导致放弃购物，满意度差
- **解决方案**：通过 Eureka RISE 四个阶段，构建社交网络链接的智能推荐系统
- **商业价值**：为用户带来 AHA 价值（顿悟、高光、进步），为商家门店带来 MAP 价值（市场潜力、用户增长、优势壁垒）

---

## 如何使用

### 方法一：使用测试页面（推荐）

1. 在浏览器中打开 `test-demo.html`
2. 点击 **"🚀 加载示范项目到仪表板"** 按钮
3. 页面会自动跳转到主仪表板（`index.html`）
4. 你可以在仪表板中看到已加载的示范项目

### 方法二：在控制台中加载

1. 在浏览器中打开 `index.html`
2. 按 F12 打开开发者工具，切换到 Console（控制台）标签
3. 输入以下命令并按回车：
   ```javascript
   loadDemoProject()
   ```
4. 页面会自动刷新，示范项目将出现在仪表板中

### 方法三：URL 参数加载

在浏览器地址栏中访问以下 URL：
```
index.html?load_demo=true
```

页面会自动加载示范项目。

## 技术说明

### 数据存储

示范项目数据存储在浏览器的 `localStorage` 中，键名为 `eureka_projects`。

### 数据结构

完整的项目数据结构定义在 `js/test-demo-project.js` 文件中的 `DEMO_PROJECT` 常量。

### 自定义项目

如果你想创建自己的示范项目，可以参考 `DEMO_PROJECT` 的数据结构，修改其中的内容后调用：
```javascript
const storage = new ProjectStorage();
storage.create(YOUR_CUSTOM_PROJECT);
```

## 常见问题

**Q: 示范项目可以修改吗？**
A: 可以。示范项目加载到仪表板后，就像普通项目一样可以编辑和修改。

**Q: 示范项目会占用存储空间吗？**
A: 示范项目存储在浏览器的 localStorage 中，占用空间很小（约 20KB）。

**Q: 可以在移动设备上使用吗？**
A: 可以。仪表板支持响应式设计，可以在手机和平板上正常使用。

**Q: 数据会丢失吗？**
A: 只要不清除浏览器缓存，数据会一直保留。建议定期导出备份。
