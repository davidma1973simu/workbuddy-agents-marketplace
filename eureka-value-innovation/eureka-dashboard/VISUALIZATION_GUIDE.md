# Eureka 仪表板可视化功能说明

## 📊 已实现的可视化组件

### 1. 甘特图 (Gantt Chart)

**位置**: 主仪表板右侧面板顶部

**功能说明**:
- 显示所有项目的时间线和进度
- 横轴：最近30天时间范围
- 纵轴：项目列表
- 进度条：根据项目状态显示不同颜色
  - 灰色：草稿状态
  - 橙色：进行中
  - 绿色：已完成
  - 深灰色：已归档
- 红色虚线：标记"今天"的位置
- 每个项目条显示进度百分比

**技术实现**:
- 使用 HTML5 Canvas 绘制
- 响应式设计，自动适应容器大小
- 自动计算项目时间位置
- 支持多项目并行展示

### 2. MAP 价值雷达图

**位置**: 主仪表板右侧面板中部

**功能说明**:
- 展示 Shape 阶段的三维商业价值评估
- 三个维度：
  - **M (Market)**: 市场潜力 (1-10分)
  - **A (Adoption)**: 用户增长 (1-10分)
  - **P (Protection)**: 优势壁垒 (1-10分)
- 动态展示选中项目的 MAP 评分
- 紫色系配色方案 (#667eea)

**技术实现**:
- 三角形雷达图布局
- 同心三角形网格背景
- 实时响应数据变化
- 数据点高亮显示

### 3. AHA 价值雷达图

**位置**: 主仪表板右侧面板中部

**功能说明**:
- 展示 Exam 阶段的三维用户价值评估
- 三个维度：
  - **A (Aha)**: 顿悟 (1-10分) - 用户感受到核心价值的程度
  - **H (Highlight)**: 高光 (1-10分) - 用户体验的高光时刻
  - **A (Advancement)**: 进步 (1-10分) - 产品带来的进步提升
- 动态展示选中项目的 AHA 评分
- 绿色系配色方案 (#10b981)

**技术实现**:
- 三角形雷达图布局
- 同心三角形网格背景
- 实时响应数据变化
- 数据点高亮显示

### 4. 流程产出总览

**位置**: 主仪表板右侧面板中部

**功能说明**:
- 展示项目四个阶段的所有产出物
- 四个阶段卡片：
  - **Reveal 🔍**: 洞察阶段
    - POV 三段式洞察
    - 用户画像数量
    - 利益相关者数量
    - 场景地图触点数量
  - **Inspire 💡**: 启发阶段
    - 创意方案数量
    - 三维评估矩阵
    - 最佳创意选择
  - **Shape 🎨**: 构建阶段
    - 四维概念方案
    - MAP 价值雷达
    - 6幕体验故事
  - **Exam ✅**: 验证阶段
    - AHA 价值评估
    - 电梯呈现
    - 30-60-90天计划
    - 商业模式画布

**技术实现**:
- 动态生成阶段卡片
- 自动统计各阶段产出数量
- 颜色编码区分不同阶段
- 响应式网格布局

### 5. 可交付资产卡片

**位置**: 主仪表板右侧面板下部

**功能说明**:
- 展示可交付的项目资产
- 四种资产类型：
  1. **项目报告 📊**
     - 描述：完整的项目文档，包含四阶段所有产出
     - 可用条件：项目进度 > 50%
     - 操作：导出 PDF

  2. **演示文稿 🎯**
     - 描述：适合向利益相关者展示的幻灯片
     - 可用条件：项目进度 > 70%
     - 操作：导出 PPT

  3. **商业模式画布 🎨**
     - 描述：9模块商业模式可视化
     - 可用条件：Exam 阶段已完成商业模式画布
     - 操作：查看

  4. **实施路线图 🗺️**
     - 描述：30-60-90天迭代计划
     - 可用条件：Exam 阶段已完成迭代计划
     - 操作：查看

**交互逻辑**:
- 可用资产：绿色左边框，主要按钮样式
- 不可用资产：灰色左边框，禁用状态，显示"待完成"
- 点击可用按钮执行相应操作

### 6. 导出功能

**位置**: 主仪表板右侧面板底部

**支持格式**:
- **PDF 导出**: 生成完整的项目报告 PDF
- **Markdown 导出**: 生成结构化 Markdown 文本，自动复制到剪贴板
- **PPT 导出**: 生成 HTML 幻灯片文件

**功能特点**:
- 一键导出，操作简便
- 包含所有四阶段数据
- 自动格式化和排版
- 支持批量导出多个项目

## 🔄 交互逻辑

### 初始化流程
1. 页面加载时初始化所有可视化组件
2. 绘制甘特图（显示所有项目）
3. 雷达图默认显示空状态

### 项目选择流程
1. 用户点击项目列表中的项目
2. 打开项目详情抽屉
3. 更新 `window.currentProjectId`
4. 调用 `initVisualizations(currentProject)` 更新所有可视化组件
5. 流程产出和可交付资产根据项目数据动态渲染

### 自动更新
- 窗口大小变化时自动重绘 Canvas 图表
- 项目数据更新时自动刷新可视化
- 实时响应编辑器中的数据修改

## 📊 数据流

```
ProjectStorage (localStorage)
    ↓
ProjectManager (项目管理)
    ↓
Visualizations (可视化组件)
    ↓
Canvas / DOM (图表渲染)
```

## 🚀 使用示例

### 查看项目可视化
1. 打开主仪表板
2. 在项目列表中点击任意项目
3. 右侧面板自动显示：
   - 甘特图（所有项目时间线）
   - 选中项目的 MAP 雷达图
   - 选中项目的 AHA 雷达图
   - 流程产出总览
   - 可交付资产列表

### 导出项目资产
1. 选择一个项目
2. 点击可交付资产卡片中的"导出"按钮
3. 或使用底部导出功能：
   - PDF 导出：生成完整报告
   - Markdown 导出：复制到剪贴板
   - PPT 导出：生成幻灯片

## 🔧 技术架构

### 核心组件
- **visualizations.js**: 可视化组件库
  - 甘特图绘制函数
  - MAP 雷达图绘制函数
  - AHA 雷达图绘制函数
  - 流程产出渲染函数
  - 可交付资产渲染函数

### 依赖关系
```
index.html
  ├─ visualizations.js
  ├─ storage.js
  ├─ project-manager.js
  └─ exporter.js
```

### 数据来源
- localStorage 中的项目数据
- 通过 ProjectStorage 类访问
- 项目 ID 通过 `window.currentProjectId` 传递

## 📝 注意事项

1. **Canvas 尺寸**: 雷达图 Canvas 建议宽高比为 1:1 或 4:3
2. **数据完整性**: 如果项目缺少某阶段数据，对应图表显示空状态
3. **性能优化**: 大量项目时，甘特图会自动调整行高
4. **浏览器兼容**: 支持现代浏览器（Chrome, Firefox, Safari, Edge）
