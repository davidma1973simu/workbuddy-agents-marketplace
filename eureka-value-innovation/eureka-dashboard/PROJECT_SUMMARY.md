## 🚀 使用流程

### 1. 创建项目
1. 点击「+ 新建项目」按钮
2. 填写项目基本信息（名称、简介、目标用户）
3. 进入编辑器开始工作

### 2. 编辑项目
1. 从项目列表点击项目卡片
2. 在详情抽屉中点击「✏️ 编辑项目」
3. 使用阶段导航器切换不同阶段
4. 填写各阶段的表单内容
5. 保存或进入下一阶段

### 3. 查看项目
1. 点击项目卡片打开详情抽屉
2. 查看项目基本信息和各阶段进度
3. 查看阶段内容摘要

### 4. 导出项目
1. 在编辑器或详情抽屉中
2. 选择导出格式：
   - 📄 **PDF**：打开打印对话框，保存为 PDF
   - 📝 **Markdown**：复制到剪贴板
   - 📊 **PPT**：下载 HTML 幻灯片文件
