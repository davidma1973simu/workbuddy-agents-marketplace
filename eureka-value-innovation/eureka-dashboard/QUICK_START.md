# Eureka 仪表板 - 快速开始指南

## 🚀 5分钟快速上手

### 1. 启动仪表板

```bash
# 进入 dashboard 目录
cd /Users/davidma/WorkBuddy/Claw/eureka_value_inovation/eureka-dashboard

# 启动本地服务器
python3 -m http.server 8080

# 打开浏览器访问
open http://localhost:8080
```

### 2. 加载示范项目

**方法一：使用测试页面（推荐）**
1. 访问 http://localhost:8080/test-demo.html
2. 点击"加载示范项目到仪表板"按钮
3. 点击"前往仪表板查看"

**方法二：在主仪表板加载**
1. 访问 http://localhost:8080/index.html
2. 打开浏览器控制台（F12）
3. 输入 `loadDemoProject()` 并按回车

**方法三：URL 参数**
1. 访问 http://localhost:8080/index.html?load_demo=true
2. 示范项目会自动加载

### 3. 查看可视化内容

1. 在项目列表中点击"智能购物推荐系统"项目
2. 右侧面板会自动显示：
   - **甘特图**：所有项目的时间线
   - **MAP 雷达图**：商业价值评估（市场潜力/用户增长/优势壁垒）
   - **AHA 雷达图**：用户价值评估（顿悟/高光/进步）
   - **流程产出总览**：四个阶段的所有产出物
   - **可交付资产**：可导出的项目资产

### 4. 编辑项目

1. 在项目详情抽屉中点击"编辑项目"按钮
2. 进入编辑器，顶部显示阶段导航器
3. 可以在四个阶段之间切换：
   - 🔍 Reveal - 洞察阶段
   - 💡 Inspire - 启发阶段
   - 🎨 Shape - 构建阶段
   - ✅ Exam - 验证阶段
4. 修改数据后自动保存

### 5. 导出项目

1. 在项目详情抽屉中点击"导出"按钮
2. 或使用右侧底部的导出功能：
   - 📄 导出 PDF - 生成完整项目报告
   - 📝 导出 Markdown - 复制到剪贴板
   - 📊 导出 PPT - 生成幻灯片

## 📊 示范项目内容

**项目名称**: 智能购物推荐系统 - 社交链接版

**目标用户**: 20-35岁都市白领女性

**核心问题**: 鞋服门店购物时的认知过载

**解决方案**: 通过 RISE 四个阶段构建智能推荐+社交分享系统

### 四阶段完整数据

**Reveal (洞察)**:
- POV 三段式洞察
- 2个用户画像
- 4个利益相关者
- 6个场景地图触点

**Inspire (启发)**:
- 3个创意方案
- 三维评估矩阵
- 最佳创意选择

**Shape (构建)**:
- 四维概念方案
- MAP 雷达图（9/8/7）
- 6幕体验故事

**Exam (验证)**:
- AHA 雷达图（9/8/10）
- 电梯呈现
- 30-60-90天计划
- 商业模式画布

## 🔧 常见问题

### Q: 如何创建新项目？
A: 点击顶部"新建项目"按钮，填写项目名称和简报即可。

### Q: 如何删除项目？
A: 在项目详情抽屉中点击"删除项目"按钮。

### Q: 如何修改项目数据？
A: 在项目详情抽屉中点击"编辑项目"按钮，进入编辑器进行修改。

### Q: 数据保存在哪里？
A: 数据保存在浏览器的 localStorage 中，不会丢失。

### Q: 如何导出项目？
A: 有三种方式导出：
  - 在项目详情抽屉中点击"导出"
  - 使用右侧底部的导出按钮
  - 在可交付资产卡片中点击对应按钮

### Q: 可视化图表不显示怎么办？
A: 确保已选择一个项目，并且项目包含相应阶段的数据。

### Q: 如何清除示范项目？
A: 在测试页面 http://localhost:8080/test-demo.html 中点击"清除示范项目"按钮。
