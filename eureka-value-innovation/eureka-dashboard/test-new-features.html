🎯 核心功能说明

1. 导出服务 (ExportService)

支持三种导出格式：

  • Markdown：生成结构化的 Markdown 文本，可直接复制到剪贴板
  • PDF：使用浏览器打印功能，自动生成可打印的 HTML 版本
  • PPT：生成 HTML 幻灯片文件，可直接用浏览器打开

2. 阶段导航器 (StageNavigator)

提供四阶段之间的快速导航：

  • 🔍 Reveal - 洞察层
  • 💡 Inspire - 启发层
  • 🎨 Shape - 构建层
  • ✅ Exam - 验证层

每个阶段显示完成进度，支持点击切换和上一页/下一页按钮。

3. 项目详情抽屉 (ProjectDrawer)

右侧滑出的详情面板，包含：

  • 项目基本信息（ID、状态、进度、目标用户）
  • 项目简介
  • 四阶段进度概览
  • 操作按钮：编辑、导出、删除

🔧 使用说明

打开项目详情抽屉

点击项目列表中的任意项目卡片，将打开右侧详情抽屉。

编辑项目

在详情抽屉中点击"✏️ 编辑项目"按钮，将进入编辑器并显示阶段导航器。

阶段切换

在编辑器顶部点击不同阶段的卡片，可快速切换到对应阶段。

导出项目

在编辑器或详情抽屉中，选择相应的导出按钮：

  • 📄 导出 PDF：打开打印对话框，保存为 PDF
  • 📝 导出 Markdown：复制 Markdown 文本到剪贴板
  • 📊 导出 PPT：下载 HTML 幻灯片文件
