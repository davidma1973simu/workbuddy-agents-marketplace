召唤 Eureka 创新教练团，帮我从 0 到 1 做这个项目？

📋 三种用法并存：技能管单点 · 专家团管全链 · Dashboard 管回填

🗣️ ① 单技能调用（最常用）
在 WorkBuddy 聊天框说一句触发话术，例如「不知道做什么创新项目，帮我找选题？」，对应技能直接开工，产出结构化卡片。适合单点问题：选题、洞察、创意、方案、验证、呈现。
🤖 ② 专家团召唤（全流程）
说「召唤 Eureka 创新教练团，帮我从 0 到 1 做这个项目？」，主理人带 8 位专家按 RISE 阶段协作，产出全链物料。也可在 WorkBuddy 客户端【专家】→【专家团】Tab 搜索召唤。
📊 ③ Dashboard 内 AI 助手
在 Eureka 项目库各阶段编辑器点「✨ AI 助手」，自动读取当前项目上下文生成内容并回填表单（需配置 API Key，配置方法见 Eureka Pro 页面）。
💡 三套资产的关系：11 个技能是单点能力，专家团把它们编成一队按阶段协作，Dashboard 是可视化工作台。三者并存互补——日常小问题用技能，完整项目用专家团，录数据和看板用 Dashboard。
