❓ 常见问题

你可能还想知道

Eureka 真的完全免费吗？以后会收费吗？⌄
完全免费，没有付费功能，没有付费计划。代码在 GitHub 上开源，你甚至可以 fork 一份部署在自己的服务器上。
我的项目数据安全吗？会上传到服务器吗？⌄
所有数据都存储在你的浏览器 localStorage 中，不会上传到任何服务器。清除浏览器缓存前，数据会一直保留。建议定期用 JSON 导出功能备份。
可以多人协作编辑同一个项目吗？⌄
当前版本是单机版，不支持实时多人协作。如果需要协作，可以导出 JSON 文件分享给团队成员，对方导入后继续编辑。多人云端协作功能在规划中。
AI 辅助功能怎么用？需要额外付费吗？⌄
AI 功能需要你自己提供 API Key（支持 OpenAI / DeepSeek / 通义千问等兼容接口）。Eureka 本身不收任何费用，AI 调用费用取决于你选择的 API 提供商。DeepSeek 的调用成本非常低，通常几分钱就能完成一次分析。
换了电脑/浏览器，数据还在吗？⌄
数据存在本地浏览器，换设备后数据不会自动同步。建议使用"导出JSON"功能定期备份，新设备上通过"导入JSON"恢复。
我不懂设计思维，能用好 Eureka 吗？⌄
完全可以。Eureka 内置了完整的使用手册和每个阶段的操作指引。每个字段都有清晰的说明，就算你是第一次接触设计思维，也能跟着引导完成整个流程。
