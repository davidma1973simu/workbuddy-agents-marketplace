## 一、一句话定位

入口 A 让你「想清楚」，入口 B 让你「做出来」。

无论你想改变的是一句话的目标、一个突然的感悟、一段学到的新认知，还是一个长期想养成的习惯——入口 B 都把它拆成「30 秒内一定能完成」的最小动作，绑定一个真实触发点，做完立刻庆祝，并持续沉淀成你的行为改变档案。

---

## 二、设计原则

1. **输入不拘形式**：感悟、新认知、学到的东西、想法、改变目标，都可以是起点。
2. **输出对齐入口 A**：和认知流程一样，最终产出「支持资源 + 身份变化」。
3. **小到不可能失败**：不通过就不能往下走。
4. **不加动机，只降难度**：没做到时不说「加油」，只问「要不要再小一点 / 换个时机」。
5. **完成即投票**：每次完成都是给「你想成为的人」投一票，与入口 A 的身份系统合并。

---

## 三、输入与输出

### 3.1 输入（任何想变成行动的东西）

| 输入类型 | 示例 |
|---|---|
| 改变目标 | 「我要减肥」 |
| 新认知 | 「AI 时代培训师要做整体架构，而非专业求精」 |
| 感悟 | 「真正影响客户的不是话术，而是我是否真的理解他的处境」 |
| 学到的东西 | 「番茄工作法的核心不是 25 分钟，而是中断后的快速重启」 |
| 想法 | 「我想每天写 200 字」 |

用户只需写一句话，系统不问理论、不分类别。

### 3.2 输出（与入口 A 同构）

| 输出 | 说明 |
|---|---|
| **微行动 + 触发点** | 30 秒内可完成，绑定一个已有的日常动作 |
| **支持资源** | 人、工具、环境提示、信息来源 |
| **身份变化** | 「我对____的全新认知 / 我已经是____的人」 |
| **行为改变档案** | 所有行动记录、连续完成、身份票累计 |

## 四、三步流程（极简版）

### Step 1 · 拆

- 用户写下一句话：想改变什么 / 一个新认知 / 一个感悟。
- 系统引导把它拆成 1 分 → 100 分的阶梯。
- **强制校验**：锁定的第一级动作必须在 30 秒内可完成。不能，就继续拆。
- AI 能力：「帮我拆」「帮我再小一点」。

### Step 2 · 绑

- 把微行动绑定到一个每天必然发生的日常动作之后。
- 句式：**「在我____之后，我就____。」**
- 可选：环境提示、庆祝动作。
- 关键：用户必须立刻做第一次，完成即庆祝。

### Step 3 · 做

- 主界面只留一张行动卡：微行动 + 锚点 +「做完了」按钮。
- 每次完成 = 给身份投一票。
- 没做到时：不显示失败，只显示诊断选项（忘了 / 太麻烦 / 不想做 / 没时间），一键调整。
- 断了 ≥3 天：不清零，提供「最小重启动作」。

## 五、与入口 A 的关系

| | 入口 A「帮我清楚」 | 入口 B「帮我改变」 |
|---|---|---|
| 解决 | 想不明白 | 想明白了但动不了 |
| 输入 | 一个问题或混乱情境 | 一句话目标 / 新认知 / 感悟 |
| 流程 | 归类 → 洞察 → 应用 → 产出 | 拆 → 绑 → 做 |
| 输出 | 洞察 + 应用计划 + 支持资源 + 身份 | 微行动 + 支持资源 + 身份票 |
| 档案 | 认知档案 | 行为改变档案 |
| 数据打通 | 洞察可直接「变成行动」 | 完成次数并入身份投票 |

**关键衔接**：入口 A 产出页新增「把它变成行动 →」按钮，自动把 `scenario / insight / identity / resourcesPlan` 带入入口 B。

```javascript

trf_actions          // 行动数组

Action {
  id, createdAt,
  sourceSessionId,          // 来自入口A的会话（可空）

  inputType,                // goal | insight | reflection | learning | idea

  // Step 1 拆

  // Step 2 绑

  // Step 3 做

  graduatedAt,

  // 输出
  support: { people, tools, info },
}

// 复用
// trf_profile.identityStatements 入口B每次完成也 push 一票（source: 'action'）
```

## 七、AI 能力边界（知行）

| 能力 | 作用 | 禁止 |
|---|---|---|
| 帮我拆 | 把输入拆成 1-100 分阶梯 | 不评价、不说教 |
| 帮我再小一点 | 给出 3 个 30 秒版本 | 不替用户决定 |
| 帮我找锚点 | 基于日常推荐 3 个触发点 | 不强制用户使用 |
| 卡住了怎么办 | 根据原因给 1 个调整建议 | 不说「加油/坚持」 |
| 找人支持 | 基于已有资源建议找谁、说什么 | 不代写消息 |

### 首页入口

| 入口 | 跳转 | 说明 |

| 开始一次梳理 | app.html | 入口 A |
| 开始一次改变 | act.html | 入口 B |

### act.html 布局（复用 app.html 三栏设计）

- 中间：当前步骤主面板

- 顶部：身份投票卡（与 archive.html 合并计票）

- 每张卡：输入原文 / 微行动 / 锚点 / 连续天数 / 总完成次数

## 十、验收标准

1. 用户能在 30 秒内完成入口 B 的首次动作设定。
2. 任何输入都能被拆到 30 秒内，拆不到不让走。
3. 完成一次微行动后，身份投票自动 +1，与入口 A 合并。
4. 没做到时，界面不出现红色/失败/催促。
5. 行为改变档案能查看所有行动、连续天数、身份票累计。
6. 首页可见「开始一次梳理」「开始一次改变」「认知档案」「行为改变档案」四个入口。
