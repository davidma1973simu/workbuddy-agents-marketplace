Eureka 技能选择指南

两个技能，两种用法。快速判断：什么场景、什么问题，该找哪个技能。
一、两个技能，一图看懂
eureka-pro-automation
全自动 RISE 创新工作流 · 一步到位
适合需求已经清楚，想快速拿到完整方案
做什么自动跑完 Build → Reveal → Inspire → Shape → Exam 共 14 步
产出完整方案 + 14 张阶段卡片 + 一页纸项目看板
耗时一次性完成，几分钟出结果
触发语"帮我跑一个完整的 Eureka 创新项目"
eureka-coach
创新卡壳教练 · 苏格拉底式引导
适合卡住了、不确定、问题还没想清楚
做什么通过提问引导你厘清"真正的问题是什么"
产出共识结论（一句话问题陈述）+ 下一步建议
耗时交互式对话，3-5 轮提问
触发语"我在 RISE 某一步卡住了，帮我理一理"
二、三步判断，找到对的技能
1你现在最需要什么？
2你的问题描述足够清楚吗？
3你正处在什么状态？
→ 使用 eureka-pro-automation
你的需求明确、目标清晰，适合让技能自动跑完 RISE 全部 14 步，直接产出完整方案与项目看板。告诉它你的问题即可。
→ 使用 eureka-coach
你正处于卡壳或不确定状态，适合先让教练通过提问帮你厘清"真正的问题是什么"，收敛出清晰的问题陈述后，再决定下一步。
三、真实范例对照
范例 A 需求明确 → eureka-pro-automation
用户输入
「我们如何才能帮助城市高退休金（月收入大于8K）、单身男性老年人（大于75岁）提供健康安全、生活辅助以及情感照顾，让他们的生活更有质量呢？」
技能做了什么
自动执行 Build → Reveal → Inspire → Shape → Exam 五阶段 14 步：构建项目简报、挖掘用户 POV 与 FIND 洞察、生成 12 个创意并筛选、四维拷问方案、构建 MVP、评估 AHA MAP（7.7/10 → GO）。
最终产出
「小陈伴老」——AI语音管家 + 银龄守护手环双端方案：AI 主动关怀 + 硬件安全兜底 + 生活服务入口 + 情感连接桥梁，¥199/月订阅，毛利率 60-67%。同时输出 14 张阶段卡片与一页纸项目看板。
范例 B 卡壳困惑 → eureka-coach
用户输入
「我在 Shape 阶段卡住了，想不出来方案」
对话过程（苏格拉底式引导）
教练
我是帮你把卡壳想清楚的教练：先接住你的困境、再深挖根因、然后收敛成一句清晰的问题结论，最后给你下一步建议。现在，你卡在哪了？
用户
我在 Shape 阶段，脑子里有很多零散的想法，但凑不成一个完整的方案。
教练
你的意思是：想法不少，但缺一条主线把它们串起来，对吗？那这些想法里，哪个是你觉得最不能丢的？
用户
最不能丢的是"老人不用学任何操作"——这是我和用户访谈里最强烈的反馈。
教练
那再深挖一层：为什么"不用学操作"对你这个项目如此关键？它背后要解决的是哪类用户的什么痛点？
用户
因为目标用户是 75 岁以上的老人，学不会复杂操作，一旦要学就会放弃。所以方案必须零门槛。
教练
清楚了。看来你的困境不是"没有想法"，而是"想法没有被一个核心约束串起来"。我现在帮你收尾。
共识结论 + 下一步
最初的问题：在 Shape 阶段凑不成完整方案
辅导过程：从"想法零散"深挖到"零门槛"这一核心约束，明确方案的唯一主线
共识结论：零散想法的解决方案缺乏一个核心约束（零操作门槛）作为主线来整合
下一步建议：以"零操作门槛"为唯一设计约束，筛掉所有需要学习成本的想法；把剩余想法按 RISE 的 Shape 四维（价值/增长/技术/商业）重新归位
四、进阶用法：组合出击

先用 coach 厘清，再用 automation 跑全流程

1
eureka-coach
问题模糊？先让教练通过提问帮你收敛出清晰的问题陈述。
→
2
eureka-pro-automation

一句话记住
问题清楚 → 找 automation（要方案）  |  问题模糊 → 找 coach（先厘清）
